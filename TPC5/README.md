# TPC 5

Neste TPC desenvolveu-se uma aplicação para gerir uma turma de alunos. Cada aluno é representado por um tuplo com o nome, o id e uma lista com as notas do TPC, do projeto e do teste, e a turma é uma lista desses alunos.

A aplicação apresenta um menu que permite criar uma turma, inserir um aluno, listar a turma, consultar um aluno pelo id, guardar a turma num ficheiro, carregar uma turma de um ficheiro e sair. 
Cada opção foi implementada numa função própria, e um ciclo while mantém o menu a aparecer até o utilizador escolher a opção 0.
