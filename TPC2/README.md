# TPC2

O TPC lançado pelo Docente na segunda aula Teórica, consistiu em criar um jogo com 2 modalidades: o computador pensa num número (entre 0 e 100), utilizador tenta adivinhar; ou, o utilizador pensa num número (entre 0 e 100) e o computador tenta adivinhar

O programa tem o nome JOGO_ADIVINHA e o jogo consiste em adivinhar o número escolhido.
