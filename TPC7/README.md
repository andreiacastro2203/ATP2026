O TPC7 (Prova de Aferição) é composto por três exercícios comalgumas alíneas para testar os conhecimentos adquiridos nas aulas.

No primeiro exercício, é preciso especificar listas em compreensão: 
os elementos não comuns a duas listas, as palavras de um texto com mais de 3 letras e pares (índice, valor) de uma lista. 

No segundo exercício, é pedido para definir quatro funções sobre strings e números:
contar ocorrências de uma substring sem sobreposição, calcular o produto dos 3 menores inteiros de uma lista, reduzir um número à soma dos seus dígitos até restar um só dígito e encontrar o índice da primeira ocorrência de uma string noutra. 

No terceiro exercício, é necessário manipular e consultar uma rede social representada por uma lista de dicionários (posts com comentários), com funções para contar posts, filtrar por autor, listar autores, inserir e remover posts, calcular a distribuição de posts por autor e encontrar os posts comentados por um autor.
