# TPC4

Este trabalho consistiu no desenvolvimento, em Python, de uma aplicação com um menu interativo que permite manipular uma lista de números inteiros. 
A aplicação guarda a lista numa variável interna e, enquanto o utilizador não escolher a opção “Sair”, executa a operação pretendida, apresenta o resultado e volta a mostrar o menu.

O menu oferece as seguintes operações: criar uma lista de números aleatórios entre 1 e 100, ler uma lista introduzida pelo utilizador, calcular a soma, a média, o maior e o menor elemento, indicar (Sim/Não) se a lista está ordenada por ordem crescente ou decrescente, e procurar um elemento, devolvendo a sua posição ou -1 caso não exista. 
Ao sair, a aplicação mostra a lista guardada nesse momento. 
Criar ou ler uma nova lista substitui a anterior.
